## 🏗️ My Engineering Philosophy

I'm moving beyond *"train model → print accuracy → done"* and toward a full pipeline mindset:

```
Problem → Data → EDA → Features → Baseline → Model →
Evaluation → Error Analysis → API → Application →
Deployment → Monitoring → Iteration
```

I care about:

- 📌 Understanding *why* a model works
- 📊 Choosing metrics based on the actual problem
- 🔍 Performing proper error analysis
- 🧪 Comparing baselines instead of blindly reaching for complex models
- 🔌 Connecting models to APIs and applications
- ☁️ Learning how systems are actually deployed
- 🧱 Writing maintainable code
- 📚 Understanding fundamentals instead of only using libraries
